# Pennywise API Server

API Server for Pennywise Money Management.

## Getting Started

Whether you are using the server for a standalone API for a custom frontend in production or for development, a database connection and related credentials, JWT secret, Service port number.

### Development

You will need `.env.development` to set environment variables for the development server.

### Production

Environment variables can be set with docker compose / your container platform, *running on bare metal is not advised*.

### Database

PostgreSQL is currently the supported database with more potentially down the line.
